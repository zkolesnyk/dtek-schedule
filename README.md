# dtek-schedule

Графіки відключень ДТЕК Київські регіональні електромережі у JSON для Divine Tools.
Збирач (GitHub Actions, раз на 15 хв) читає публічну сторінку `dtek-krem.com.ua/ua/shutdowns`
у звичайному headless-браузері й кладе `schedule.json` у гілку `data`.

- `days` — `{дата: {група: [48 пів-годин]}}`: 0 — світло є, 1 — відключення, 2 — можливе.
- `addresses` — для вулиць із секрету `STREETS`: група кожного будинку й поточне відключення за даними ДТЕК.
- `dtek_updated` — коли ДТЕК оновив графік, `fetched_at` — коли зібрано.
- `catalog.json` — довідник будинків міст із `STREETS`: `{cities: {місто: {вулиця: {будинок: група}}}}`, оновлюється раз на добу.
